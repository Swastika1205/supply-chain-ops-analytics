# Operations Dashboard Layer

The dashboard is designed for an executive operations / consulting review.

## Pages

### 1. Executive Operations Overview
- Shipment volume
- On-time delivery %
- SLA breach rate
- Average delay days
- Estimated delay cost
- monthly service trend

### 2. SLA & Delay Diagnosis
- SLA breach rate by carrier
- Average delay by carrier
- Delay reasons
- Tier-1 vs Tier-2 performance

### 3. Carrier / Region Performance
- Carrier × region matrix
- service/cost trade-off
- high-risk combinations
- shipment volume context

### 4. Bottleneck Prioritization
- delay reason ranking
- estimated cost exposure
- priority score
- recommended intervention band

These visuals are designed around **observation → root cause → impact → action**.
